# TripTogether

TripTogether 是一个面向小组出行的旅行规划 Web 应用：从建团、邀请成员、按天排行程，到路线加油规划、寻找同行小组、盲盒行程和旅途中的任务 Bingo，帮助一群人把旅行从计划到完成都一起搞定。

## 技术栈

|---|---|---|
| 框架 | Next.js 16（App Router）+ React 19 | 在用 |
| 语言 | TypeScript | 在用 |

| 登录 | Better Auth（邮箱 + 密码，接 Drizzle） | 在用 |
| 测试 | Node 自带的 `node:test` | 在用 |
| 代码检查 | ESLint | 在用 |
| 包管理 | npm | 在用 |

- 部署暂不考虑，先在本地跑通。
- 加油规划统一使用 Google Routes、Places API (New) 单站油价与 Google 地图；DeepSeek 仅识别车型。实时聊天、图片存储等其他功能的服务待定。

## 基础模块

### 用户注册与登录
- 注册、登录、退出

### 旅行管理
- 创建、查看、修改、删除旅行
- 填写出发地、目的地和日期

### 成员邀请
- 通过邀请码加入旅行
- 查看成员列表
- 退出旅行

### 行程规划
- 按天查看旅行的完整行程，每天一站
- 所有成员都可以给某一天添加、修改、删除安排：时间（可不填）、做什么、地点、备注
- 每条安排显示是谁添加的；同一天内，没定时间的排在前面，其余按时间排序
- 旅行日期改短后，落在日期之外的安排会单独标出，提醒挪到行程内的某天或删除

## 创新功能

加油规划模块统一命名为 **Gasoline Intelligence**。
登录后点击同名导航或旅行详情入口，进入 `/trips/gasoline-intelligence`。
车型识别、最低花费规划和地图的设计、配置及接口见 [加油规划说明](docs/gasoline-intelligence.md)，key 配置见 [Google Maps 步骤](docs/google-maps-setup.md)，实际车型提示词及调用流程见 [DeepSeek 提示词](docs/deepseek-prompts.md)，对应源码在 `lib/gasoline-intelligence/prompts.ts`。

### 1. 查油价与加油规划
- **输入**：出发地、目的地、车辆油耗、油箱容量、当前油量、加油会员身份、停靠偏好
- **数据**：查询沿途加油站与各地区油价，识别均价最低的区域，以及油价突然升高或降低的路段
- **推荐**：在路线两侧走廊内的加油站里，精确求出全程加油花费最少的停靠站和每站加油量；绕路多烧的油计入花费，停靠只为加油，不为休息间隔
- **展示**：结果在地图上呈现
- **AI**：DeepSeek 识别车型参数；路线及单站油价使用 Google API，推荐与加油量由服务端规划器计算

### 2. 旅行小组匹配
- 小组定好大致旅行计划后，可发布到「共享大厅」
- 其他小组发现行程相近（目的地、日期等相似）时可发起匹配
- 对方同意后双方开启聊天，商量是否结伴

### 3. 旅行盲盒
- 用户设置目的地、预算、可用时间和活动偏好
- 系统从符合条件的候选景点、餐厅或活动中随机抽取，生成「神秘行程」
- 团队成员可各自提交隐藏选项，抽取后统一揭晓，给选择困难的小组增加惊喜和趣味

本地版本已实现：从旅行详情页点击 **Open travel blind box** 进入。组织者设置条件并揭晓，成员可提交
保密选项，抽取后可将结果一次性加入原行程。内置 Chicago、New York、San Francisco 演示候选，其他目的地
可通过成员提交使用；费用按每人 USD 估算，不含交通费。数据保存在 PostgreSQL 中。
设计、接口和验证步骤见 [`docs/blind-box.md`](docs/blind-box.md)。

### 4. 旅行任务 Bingo
- 每个地区维护一个任务库，存放当地可以做的事（例如芝加哥：去海军码头看日出、晚上去某栋楼的楼顶看夜景、拍一张全组合照）
- 小组出发前生成一张 Bingo 卡，旅行中完成任务即打卡，连成一线即完成 Bingo
- 任务由用户上传，经 app 审核后加入任务库
